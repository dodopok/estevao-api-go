# estevao-api-go
POC da Estevão API em go

## Pull requests

O título segue Conventional Commits em inglês, como os commits
(`feat(calendar): …`, `fix(easter): …`), e a descrição segue o modelo em
`.github/pull_request_template.md` (por quê, o que muda, riscos, deploy, como
desfazer, como testar, checklist). O GitHub só preenche o modelo na tela web:
quem abre PR pela API ou pela linha de comando copia as seções e preenche cada
uma, com "Nada." onde não se aplica.
